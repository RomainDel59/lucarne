# Security policy

## Supported versions

Security fixes are provided for the latest released version.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use the private security advisory feature of the source repository and include:

- the affected version;
- reproduction steps;
- the expected and observed behavior;
- any known impact or mitigation.

Reports are acknowledged as soon as possible. Please allow maintainers time to investigate and prepare a coordinated fix before public disclosure.
